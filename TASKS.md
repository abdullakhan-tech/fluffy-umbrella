# Roadmap

## Foundation
- [x] Responsive web UI and multilingual chat interface
- [x] FastAPI chat and health endpoints
- [x] Server-side provider key configuration
- [x] Browser-local notes/history/preferences
- [x] CSS holographic effects and motion toggle
- [x] Role-instruction specialist modes

## Reliability and security
- [ ] Add automated frontend and backend tests
- [ ] Add rate limiting and abuse protection
- [ ] Add production logging with secret/prompt redaction
- [ ] Add CI checks and dependency update policy
- [ ] Add deployment health checks and documented rollback

## Product expansion
- [ ] Authentication and account management
- [ ] Encrypted, user-controlled synced memory
- [ ] Document upload, parsing, embeddings, and RAG
- [ ] Real agent orchestration with approval gates
- [ ] Image/video generation provider integration
- [ ] Real 3D avatar model and optional voice pipeline
- [ ] Desktop packaging and Android app wrapper

## Release discipline
Only mark an item complete after implementation and verification. Mock UI does not count as a working integration.
